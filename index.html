Use {NOME} para o primeiro nome do candidato. As mensagens são usadas nos botões de envio das abas Aprovados e Reprovados.

Como usar: marque a caixinha Confirmado quando o candidato responder. Ajuste data e horário direto nos campos de cada linha — a agenda reordena e reagrupa por dia sozinha. Quando faltarem 15 minutos para uma entrevista, a linha acende e aparece um aviso no topo (com som, se ativado).

Salvo na nuvem: cada alteração vai direto para o banco de dados no Supabase, então a agenda é a mesma em qualquer computador ou celular. Se duas pessoas estiverem com a página aberta, as duas telas se atualizam sozinhas. O indicador Sincronizado no topo fica vermelho se algo não conseguir ser salvo — se isso acontecer, confira a internet e recarregue a página.
